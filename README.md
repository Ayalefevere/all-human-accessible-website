Dit is het design voor de website van Visual Thinking. Op de website kunnen studenten en docenten leren om hun gedachten en doelen te verbeelden. De website bestaat (op dit moment) uit 2 pagina's: home en tekenmethodes. De home pagina hoeft op dit moment niet uitgewerkt worden. Alle pagina's hebben een header en footer. Op de tekenmethodes pagina kun je filteren op de tekenmethodes en daar kun je de categorieeën bekijken die daar bij horen. De website is responsive voor mobile en beetje desktop.

## Veranderingen
- Ik heb de feedback verwerkt. Hamburger menu, border kleur donkerblauw bij elke categorie behalve kennisclip.
- De pagina's tekst, searchbalk tekst, icoontjes en border heb ik veranderd naar donkerblauw. Het contrast is dan beter.
- Tekstkleur in het tekstblok met de vraag/quote veranderd naar donkerblauw voor beter contrast
- Tekenmethodes titel tekst naar donkerblauw voor beter contrast
- Schaduw in button header weg
- Hoverstates gemaakt bij linkjes
- 


**HTML**
In de header staat de bovenkant van de pagina. Hierin staat het logo, navigatiemenu en icoontjes met een zoek optie voor de hele website, profile icon, favoriete en een button om materiaal te uploaden.

In de main staat alle informatie over de pagina. Tekenmethodes pagina de zoekbalk, tekenmethodes filtering en de tekenmethodes met categorieën zelf.

In de footer staat logo, sociale media icons, menu en copyright tekst.
